# project_sandpie-webgpu-engine

> From-scratch hand-written WebGPU LLM engine (modules/webgpu-engine.js) — own WebLLM-equiv, raw WGSL kernels; Phase1 Qwen3-0.6B, Phase2 Qwen3.5-0.8B

_Design note written during development (sandpie session memory); names like `TabInfer*` refer to the pre-extraction identifiers, now `TabInfer*`._

New sandpie backend: a **from-scratch WebGPU inference engine** with hand-written WGSL kernels — no TVM/MLC, no onnxruntime, no library. Inspired by HF Space `webml-community/gemma-4-webgpu-kernels` (552KB single JS, raw WGSL, ~100× faster than other backends on the user's own laptop — that empirical datapoint is the whole thesis, overrides the unverified iGPU folklore in [[project_sandpie-local-runtime-strategy]]).

**Started 2026-06-19, commit `4ac4c4e`** — `modules/webgpu-engine.js` (`window.TabInferWebGPU`) + `docs/webgpu-engine-test.html` harness. v0 = generic engine core ONLY (GPU init + capability report, buffer helpers, Jinja-lite WGSL templater, pipeline cache, portable 16×16 tiled f32 GEMM + `selfTest()`/`bench()`). NOT wired into providers.js/picker yet (host-contract methods stubbed) — so no `?v=` / HTML script tag yet either. Open the harness via the `sandpie` launch.json server (python http.server :8137) at `/docs/webgpu-engine-test.html`.

1. **WebGPU command buffers are SINGLE-USE.** Submitting the same recorded GPUCommandBuffer twice = validation error / no-op. So "command-replay" (record-once, submit-many) is IMPOSSIBLE in WebGPU. The reference engine's "replay/stable dispatch shape" must mean cheap RE-recording with cached bind groups, not literal replay. DON'T pursue replay.
2. **Decode is GPU-BOUND, not CPU-bound.** Clean split (record-without-submit = CPU encode; submit-once = GPU): **CPU encode 13ms/tok (9%), GPU execute 132ms/tok (91%).** So batching/replay/bind-group-caching can save AT MOST ~9% → not worth it. (This is why my submit-batching attempt did nothing.)

Each removed dispatch ≈ saves ~0.29ms. Secondary: 4-bit weights + subgroup GEMV reduce per-dispatch work.
